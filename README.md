# Сен үшін хат — сайт-приглашение в театр

Маленькая интерактивная история для одного человека:
**конверт → письмо → наши фотографии → квест за билетом → билет в театр Н. Жантөрин**.

React + Vite + Tailwind CSS 4. Без сервера, без базы, без регистрации — чистая статика.

## Запуск

```bash
npm install
npm run dev        # локально: http://localhost:5173
npm run build      # сборка в папку dist/
```

## Что и где менять

Все тексты, вопросы викторины, фотографии и данные билета — в одном файле
**`src/content.ts`**. Код компонентов трогать не нужно.

### Фотографии

1. Положи файлы в `public/photos/` (jpg / png / webp; лучше до 1–2 МБ каждая).
2. Перечисли их в `src/content.ts` → `gallery.photos`:

```ts
photos: [
  { src: 'photos/01.jpg', caption: 'Алғашқы кездесу', date: '12.05.2025' },
  { src: 'photos/02.jpg', caption: 'Теңіз жағасы' },
  { src: 'photos/03.jpg' },
],
```

`caption` и `date` необязательны. Пока список пустой — показываются аккуратные плейсхолдеры.
Первые 3–4 фото также используются в игре «Найди пару».

### Билет

В `src/content.ts` → `ticket`: название спектакля (`play`), дата (`date`), время (`time`),
ряд/место (`row`, `seat`). Фото или скан настоящего билета положи в `public/ticket.jpg`
и укажи `image: 'ticket.jpg'` — он появится после «отрыва» корешка.

### Квест

- `quest.quiz.questions` — три вопроса «насколько ты нас знаешь», у каждого три варианта
  и номер правильного (`answer`: 0, 1 или 2).
- `quest.scratch.secret` — что скрыто под стирающимся слоем.
- Игра «Найди пару» собирается автоматически из фотографий (или значков, если фото нет).

## Публикация на GitHub Pages

1. Создай пустой репозиторий на GitHub (например `theatre-invite`).
2. В папке проекта:

```bash
git remote add origin https://github.com/<твой-логин>/theatre-invite.git
git push -u origin main
```

3. На GitHub: **Settings → Pages → Source: GitHub Actions**.
4. Через минуту сайт будет на `https://<твой-логин>.github.io/theatre-invite/`.

Каждый следующий `git push` в `main` обновляет сайт автоматически (см. `.github/workflows/deploy.yml`).

## Структура

```
src/
  content.ts            ← все тексты и настройки
  App.tsx               ← последовательность экранов
  index.css             ← палитра, бумажные текстуры, 3D-анимации
  hooks.ts              ← reduced-motion, появление секций
  components/
    Envelope.tsx        ← конверт с сургучной печатью
    Letter.tsx          ← письмо, разворачивающееся из трёх частей
    Gallery.tsx         ← Polaroid-галерея
    Quest.tsx           ← викторина, стирающаяся карточка, «найди пару»
    Ticket.tsx          ← билет с отрывным корешком
public/
  photos/               ← сюда фотографии
  ticket.jpg            ← (необязательно) фото билета
```

Анимации уважают `prefers-reduced-motion`: при включённой настройке всё появляется сразу, без движения.
